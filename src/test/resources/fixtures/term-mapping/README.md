# T01 固定验收样本

这些是专为工程验收编写的 **8 对合成字幕**，不是实际影视字幕，也不是经用户人工审核的质量评估集。用途是固定业务口径，供 T02～T07 逐步转为行为测试；不能以这些样例通过来宣称真实抽取准确率。

每个子目录包含一对 `.chs.srt` / `.cht.srt`，UTF-8 编码；04 的简体文件额外带 BOM。现有 Reader 不递归，读取时传入具体样例子目录，不能把本目录直接当作包含 8 对字幕的输入目录。

机器可读的验收基准为 [expected.json](expected.json)。`simplified_positions` 和 `traditional_positions` 是**各自文件内从 1 开始的位置**，不是 SRT 原编号。编号、时间和原文由对应 SRT 提供；合并单元按位置顺序连接，展示换行不构成词语差异。

## 已固定的业务口径

- 字形关系 `ORTHOGRAPHIC` 与地区词汇 `REGIONAL` 默认收录为候选。
- 专名地区译法标为 `PROPER_NAME`。所有候选均为 `PENDING_REVIEW`，专名尤其不能自动发布。
- 同一处差异取最小完整词语或固定短语，不额外输出单字关系和覆盖相同差异的大词组。例如“学习”不另拆成“学→學、习→習”。
- 两侧完全相同或只有标点、空白、展示标签变化，本地筛选后不送去抽取；若单独用这些行测试模型协议，则预期 `no_mapping`。
- 时间对齐不保证语义相同。语义冲突时 `uncertain`，不能只因两个词同时出现在相同位置就建立对应关系。
- 无可靠对齐的条目为 `UNALIGNED`，不送模型，不伪装成 `no_mapping`。
- 简繁文件标记只确定字形；来源和目标地区保持 `UNKNOWN`。
- 这些样例中的映射清单是完整预期集合，顺序不作为验收条件；无额外关系才符合样例口径。

## 逐例预期

下表中的 S/T 均指简/繁侧文件内位置；`[1] ↔ [1,2]` 表示一对多。

| 样例 | 应对齐位置 | 应提取关系 | 应忽略 / 无法确定 |
| --- | --- | --- | --- |
| 01-orthographic | S[1] ↔ T[1] | 学习 → 學習，ORTHOGRAPHIC | 不另输出字符级映射或句号 |
| 02-regional | S[1] ↔ T[1]；S[2] ↔ T[2] | 软件 → 軟體；鼠标 → 滑鼠，均 REGIONAL | 不从 cht 推断台湾地区 |
| 03-proper-name | S[1] ↔ T[1] | 赫敏 → 妙麗，PROPER_NAME，待审核 | “哈利波特中的”两侧相同，不输出 |
| 04-ignore | 三条逐一对应 | 无 | 第 1 条相同；第 2 条仅叹号形式差异；第 3 条仅标签、换行/空白差异；均本地跳过 |
| 05-uncertain | S[1] ↔ T[1]，时间一致 | 无 | “他同意了 / 他拒絕了”语义冲突，uncertain；禁止同意 → 拒絕，也禁止补造原文不存在的“拒绝” |
| 06-time-offset | 四条逐一对应，T 比 S 晚 2,000 ms | 第 3 条再见 → 再見，ORTHOGRAPHIC；第 4 条软件 → 軟體，REGIONAL | 前两条相同；前三条提供可靠文本锚点，不能简单以原始时间差超过阈值全部丢弃 |
| 07-split-merge | S[1] ↔ T[1,2]；S[2,3] ↔ T[3] | 第一个单元：安装 → 安裝，ORTHOGRAPHIC；软件 → 軟體，REGIONAL。第二个：鼠标 → 滑鼠，REGIONAL | “使用”相同；双方条数都是 3，但不能按位置逐一对应；原编号 10/20/30 与 2/4/8 不参与连接 |
| 08-unaligned | 前三条逐一对应 | 第 3 条再见 → 再見，ORTHOGRAPHIC | 前两条相同；S[4] 与 T[4] 时间和内容均不匹配，分别 UNALIGNED；不把软件 → 明天出發当关系 |

06 的偏移定义为 `traditionalTime - simplifiedTime`。08 的可靠锚点偏移为 0，不能因第四条相差 50 秒而替整份文件重新估计错误偏移。05 允许时间对齐后由语义抽取返回 uncertain；若未来增加语义拒配策略，需显式调整设计与样例，不能静默修改期望。

## expected.json 约定

- `fixture_version`：验收基准版本。业务口径变化需同步说明变更原因。
- `units`：预期对齐单元；`status=mapped` 时 mappings 非空，其他状态为空。
- `skip_identical / skip_punctuation / skip_formatting`：夹具层的本地筛选预期，不是模型响应 schema 的新枚举。
- `uncertain`：已对齐但无法建立可靠词语映射，应送模型并计入无法确定的统计。
- `unaligned_*_positions`：单独记录两侧未匹配条目；它们不出现在 units 中。
- `expected_offset_ms`：该样例的全局时间偏移，不要求用某一特定算法获得。

本组共 19 条简体、19 条繁体，17 个预期对齐单元，其中 9 个 mapped、7 个本地跳过、1 个 uncertain；共 10 条带出处的映射预期，两侧各有 1 条 UNALIGNED。相同词语关系在不同样例出现时保留独立证据，不在夹具层跨文件去重。
